# Antigravity Execution Rules

- **Strict Scope Control**: Only modify files explicitly requested or directly required to complete the task.
- **No Unrequested Changes**: Do not refactor unrelated code, alter styling, rename functions, or add unrequested files or dependencies.
- **Plan Before Major Changes**: For multi-file tasks, architectural modifications, or complex features, present an implementation plan first and request user confirmation before editing code.
- **Preserve Existing Contracts**: Maintain existing API contracts, database schemas, function signatures, and code comments unless explicitly instructed otherwise.
- **Empirical Verification**: Run verification tests or commands after completing edits to confirm functionality and build integrity before finishing.
